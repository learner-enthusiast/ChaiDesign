# ChaiDesign

ChaiDesign is a zero-dependency utility class engine and documentation site inspired by utility-first styling workflows.  
Instead of a build-time CSS compiler, ChaiDesign applies styles at runtime by parsing classes with a chai- prefix, converting them into inline styles, and then removing those classes from the DOM.

The project is currently built with Vite and vanilla JavaScript.

## What This Project Does

- Provides a custom utility syntax such as chai-p-16, chai-bg-blue-500, chai-flex, chai-rounded-8.
- Maps utility classes to CSS properties through a lightweight JavaScript engine.
- Supports many common utility groups:
  - spacing
  - color
  - typography
  - layout
  - borders and shadow
  - transforms and transitions
  - miscellaneous behavior utilities
- Includes a docs-style UI with sectioned reference tables and a sidebar navigation.

- package.json: scripts and project metadata.

## How The Utility Engine Works

1. Detects all class names that start with chai-.
2. Strips the chai- prefix.
3. Resolves each class in two phases:
   - exact utility match (for fixed classes like flex, hidden, uppercase)
   - prefix-based utility match (for dynamic classes like p-16, bg-blue-500, text-14)
4. Applies corresponding inline styles on target elements.
5. Removes processed chai-\* classes from the class list.
6. Uses MutationObserver to process newly added DOM nodes automatically.

## Utility Categories Implemented

The engine currently includes support for:

- Spacing: p, px, py, m, mx, my, pt, pb, pl, pr, mt, mb, ml, mr
- Typography: text size, text color, align, font weight, transform, decoration, leading, tracking
- Color: bg and text color utilities with scale shades
- Layout: display, flexbox helpers, grid templates, gap
- Sizing: width, height, min/max dimensions
- Positioning: relative, absolute, fixed, sticky, inset, z-index
- Border and Radius: border widths, sides, colors, rounding
- Effects: shadow, opacity, overflow
- Interactivity: cursor, pointer, select
- Transform and Motion: rotate, scale, translate, transition, duration, easing
- Miscellaneous: visibility, object-fit, aspect ratio, list style, box sizing, white-space, break behavior, resize, background helpers

## Current State Notes

While reviewing the codebase, there are a few important implementation gaps to be aware of:

- index.html currently has an empty body in source.
- main.js assumes existing elements like nav and utility sections already exist in DOM.
- index.html contains full markup and appears ahead of source state.
- index.html includes a theme toggle button with onclick calling toggleTheme, but no toggleTheme implementation is present in main.js.
- main.js defines generateColorUtilities but does not currently render a color palette section with that function.

This means the source and built output are not fully synchronized right now.

## Recommended Next Improvements

- Move full page markup from build output back into source entry markup.
- Implement and wire the theme toggle behavior in source JavaScript.
- Complete color palette rendering using the existing color utility generator.
- Add null-safety guards for required DOM queries (for example nav and required section roots).
- Add lightweight tests for utility parsing and style mapping behavior.

## Why ChaiDesign Is Interesting

- No CSS framework runtime dependency.
- Utility classes are interpreted directly in JavaScript.
- Useful for learning utility systems and style parser architecture.
- Easy to extend by adding new exact or prefix handlers in one place.
